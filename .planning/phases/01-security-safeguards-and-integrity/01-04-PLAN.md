# Plan 01-04: Restore and Enforce WebView Content Security Policy

## 1. Goal
Restore the strict Content Security Policy (CSP) defined in `docs/SECURITY_AUDIT.md` within `tauri.conf.json`, ensuring the application webview is strictly restricted to local execution and cannot initiate outbound network connections.

## 2. Context & Locations
- File: `src-tauri/tauri.conf.json` (line ~25)
- In commit `030dfff`, `"csp": null` was temporarily set.
- According to `docs/SECURITY_AUDIT.md`:
  ```json
  "csp": "default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data: asset:; font-src 'self' data:; connect-src 'self' ipc: http://ipc.localhost"
  ```

## 3. Implementation Tasks
- [ ] Update `src-tauri/tauri.conf.json` security section with the strict CSP string.
- [ ] Verify that UI rendering, local icons, inline styling, and Tauri IPC commands function seamlessly under the active CSP.
- [ ] Run `npm run build` and `cargo check --manifest-path src-tauri/Cargo.toml` to ensure the configuration validates cleanly.

## 4. Verification Criteria
- `npm run build` succeeds.
- `cargo check --manifest-path src-tauri/Cargo.toml` succeeds.
- Webview CSP blocks external network calls (`connect-src 'self' ipc: http://ipc.localhost`).
