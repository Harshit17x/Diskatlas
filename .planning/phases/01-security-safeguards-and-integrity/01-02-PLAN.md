# Plan 01-02: Path Canonicalization & Traversal Safeguards

## 1. Goal
Ensure that security safeguards evaluate canonical paths to prevent evasion via relative directory traversal segments (`..`), uncanonicalized symlinks, or alternate path representations.

## 2. Context & Locations
- File: `src-tauri/src/services/cleanup/safeguards.rs`
- In `is_system_critical_path()` and `evaluate_path_risk()`:
  - Traversal segments like `/Users/foo/../../System/Library` or `C:\Users\foo\..\..\Windows` could evade prefix string matching.

## 3. Implementation Tasks
- [ ] Add pre-validation in `safeguards.rs`:
  - Check `path.components().any(|c| c == std::path::Component::ParentDir)`. If present, reject or resolve before evaluating.
  - Attempt `std::fs::canonicalize(path)` on existing targets.
  - If canonicalization succeeds, evaluate security whitelist checks on the canonical path.
  - If the target does not exist on disk, normalize the components and verify against the whitelist.
- [ ] Update `test_system_critical_path_detection` in `safeguards.rs` to include relative traversal test vectors (`/Users/../System/Library`, `C:\Users\..\Windows\System32\drivers\boot.sys`).
